### How this file grows

- A new concept gets its own `<concept-name>.md` file next to this index,
  and one line here linking it, under the right section, with its status.
- Statuses move forward as understanding deepens (`introduced` →
  `practiced` → `solid`) and can also move backward if a gap turns out to
  be bigger than it looked.
- If a concept file is edited, this line's status should be checked too —
  they should never disagree about where things stand.
